# Sprint 3 Implementation Plan: Strategic Expansion

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Transform the planning workbench into a dynamic reallocation engine capable of handling complex, multi-segment budget optimizations with visual feedback.

**Architecture:** Moving from global budget sliders to per-segment granular control. Projections will be calculated by aggregating segment-specific response curves. Scenarios will be persisted to allow for comparison.

**Tech Stack:** Next.js 15, Drizzle ORM, PostgreSQL, Tailwind v4.

### Task 2: Persistence Layer for Scenarios

**Objective:** Create a `scenarios` table to save and reload budget configurations.

**Files:**
- Create: `marginguard-incentives/lib/db/schema.ts` (Add `scenarios` table)
- Modify: `marginguard-incentives/lib/db/repo.ts` (Add `saveScenario`, `getScenarios`)

**Step 1: Define Table**
```typescript
export const scenarios = pgTable("scenarios", {
  id: uuid("id").defaultRandom().primaryKey(),
  name: text("name").notNull(),
  config: text("config"), // JSON string of segment budgets
  totalSpend: decimal("total_spend"),
  projectedDelta: integer("projected_delta"),
  createdAt: timestamp("created_at").defaultNow(),
});
```

**Step 2: Run DB Push**
`npm run db:push`

**Step 3: Implement Repo Functions**
Add `saveScenario` and `getScenarios` to `repo.ts`.
